# TikTok 认领与发布

本流程在妙手公用采集箱中完成商品编辑、保存和清理后使用。它把商品认领到 TikTok 采集箱，再按配置为当前商品选择指定店铺并发布。

## 触发条件

只有以下条件全部满足时才进入本流程：

- 商品标题、内容、属性、变体、图片、规格、价格和库存已经保存，并刷新复核。
- 本次未采用的采集记录已经清理；最终采用记录的标题和货源 ID 已核对。
- `mark-collected` 已成功，且 `publication.auto_claim_tiktok` 为 `true`。
- 页面处于已登录的妙手账号；遇到登录、验证码、权限或接口异常时暂停并交给用户。

## 认领到 TikTok

1. 在妙手公用采集箱中按完整商品标题和货源 ID 定位最终记录，确认不是其他商品。
2. 点击该行的“认领到”，选择“TikTok”，等待成功提示或记录状态变化。
3. 打开 TikTok 采集箱（通常为 `/tiktok/collect_box/items`），在“未发布”中按完整标题和货源 ID 重新核对商品。
4. 认领失败、出现多个同名记录或货源 ID 不一致时停止，不要凭标题猜测。

## 选择店铺

按 `publication.store_selection` 选择店铺：

1. 只选当前目标商品；不要因为“全选店铺”而全选采集箱中的其他商品。
2. 点击“选择店铺”。`all` 模式切换到账号可用的全部店铺范围并勾选“全选”；`named` 模式只勾选 `publication.store_names` 中的精确名称。
3. 读取弹窗显示的已选数量，必须与 `publication.expected_store_count` 相等；`named` 模式还必须逐一确认每个配置名称都已勾选，且没有额外店铺。
4. 店铺名称不存在、重复、未加载或数量不明确时停止，不要凭相似名称猜测。

`all` 只表示当前账号当时可见的全部店铺，不表示其他账号或站点；`named` 的名称必须与当前页面显示完全一致。

## 发布

1. 对当前已核对的单个商品点击行内“发布”，或在只选中这一行后点击“批量发布”。
2. 在发布配置中再次检查选择的店铺名称和数量仍符合配置，发布方式为 `publication.publish_mode`（默认“立即发布”）。
3. 不勾选付费推广、自动提报或其他未配置的附加服务；这些选项会产生额外费用或改变运营动作。
4. 检查标题、主图、SKU 数量、价格、库存和店铺数量后，等待用户在最终“确认发布”动作前确认。该按钮会对 TikTok 店铺产生外部发布结果，即使用户开启了自动流程也不能跳过这个动作时确认。
5. 点击“确认发布”后等待成功提示，切换到“已发布”并按标题、货源 ID 和配置中的店铺逐一复核。没有成功提示、只发布到部分店铺或仍停留在“未发布”时，不得报告已发布。

## 失败与恢复

- 发布配置中的店铺数量、商品数量或货源 ID 发生变化时，取消当前发布窗口，重新定位商品。
- 页面刷新、会话失效或发布结果不明时，先查询“已发布”和“未发布”，不要重复点击发布。
- 付费、授权变更、验证码、侵权提示或覆盖已有店铺商品时停止并交给用户。
